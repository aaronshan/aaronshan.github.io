safe-rm重新封装了/bin/rm,它可以用来保护重要文件。

安装方法：

sudo apt-get install safe-rm

此时重要的目录或文件就不会被删除，例如：

$ sudo rm -rf /usr
Skipping /usr

可以通过配置/etc/safe-rm.conf 或 ~/.safe-rm 添加你的需要保护的路径或文件。
