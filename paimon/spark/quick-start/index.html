快速开始

准备工作​

Paimon 支持以下 Spark 版本及其对应的 Java 和 Scala 兼容性。我们建议使用最新的 Spark 版本以获得更好的体验。

  • Spark 4.x(包括 4.1、4.0):基于 Java 17 和 Scala 2.13 预构建

  • Spark 3.x(包括 3.5、3.4、3.3、3.2):基于 Java 8 和 Scala 2.12/2.13 预构建

下载对应版本的 jar 文件。

版本Jar (Scala 2.12)Jar (Scala 2.13)
Spark 4.1-paimon-spark-4.1_2.13-2.1-SNAPSHOT.jar
Spark 4.0-paimon-spark-4.0_2.13-2.1-SNAPSHOT.jar
Spark 3.5paimon-spark-3.5_2.12-2.1-SNAPSHOT.jarpaimon-spark-3.5_2.13-2.1-SNAPSHOT.jar
Spark 3.4paimon-spark-3.4_2.12-2.1-SNAPSHOT.jarpaimon-spark-3.4_2.13-2.1-SNAPSHOT.jar
Spark 3.3paimon-spark-3.3_2.12-2.1-SNAPSHOT.jarpaimon-spark-3.3_2.13-2.1-SNAPSHOT.jar
Spark 3.2paimon-spark-3.2_2.12-2.1-SNAPSHOT.jarpaimon-spark-3.2_2.13-2.1-SNAPSHOT.jar

你也可以从源码手动构建包含依赖的 bundled jar。

要从源码构建,先克隆 git 仓库,然后使用以下命令构建 bundled jar。

# build paimon spark 3.5 with scala 2.12
mvn clean package -DskipTests -pl paimon-spark/paimon-spark-3.5 -am

# build paimon spark 3.5 with scala 2.13
mvn clean package -DskipTests -pl paimon-spark/paimon-spark-3.5 -am -Pscala-2.13

# build paimon spark 4.0
mvn clean package -DskipTests -pl paimon-spark/paimon-spark-4.0 -am -Pspark4

# build paimon spark 4.1
mvn clean package -DskipTests -pl paimon-spark/paimon-spark-4.1 -am -Pspark4

对于 Spark 3.5,你可以在 ./paimon-spark/paimon-spark-3.5/target/paimon-spark-3.5_2.12-2.1-SNAPSHOT.jar 找到 bundled jar。

环境搭建​

信息

如果你使用 HDFS,请确保已设置环境变量 HADOOP_HOME 或 HADOOP_CONF_DIR。

Step 1: 指定 Paimon Jar 文件

启动 spark-sql 时,将 paimon jar 文件路径追加到 --jars 参数中。

spark-sql ... --jars /path/to/paimon-spark-3.5_2.12-2.1-SNAPSHOT.jar

或者使用 --packages 选项。

spark-sql ... --packages org.apache.paimon:paimon-spark-3.5_2.12:2.1-SNAPSHOT

另外,你也可以将 paimon-spark-3.5_2.12-2.1-SNAPSHOT.jar 复制到 Spark 安装目录下的 spark/jars 中。

Step 2: 指定 Paimon Catalog

  • Catalog
  • Generic Catalog

启动 spark-sql 时,使用以下命令注册名为 paimon 的 Paimon Spark catalog。仓库的表文件存储在 /tmp/paimon 下。

spark-sql ... \
    --conf spark.sql.catalog.paimon=org.apache.paimon.spark.SparkCatalog \
    --conf spark.sql.catalog.paimon.warehouse=file:/tmp/paimon \
    --conf spark.sql.extensions=org.apache.paimon.spark.extensions.PaimonSparkSessionExtensions

catalog 使用 spark.sql.catalog.(catalog_name) 下的属性进行配置。在上述例子中,'paimon' 是 catalog 名称,你可以将其改为自己喜欢的 catalog 名称。

spark-sql 命令行启动后,运行以下 SQL 创建并切换到数据库 default。

USE paimon;
USE default;

切换到该 catalog(USE paimon)后,Spark 中已有的表将无法直接访问,你可以 使用 spark_catalog.${database_name}.${table_name} 访问 Spark 表。

启动 spark-sql 时,使用以下命令注册 Paimon 的 Spark Generic catalog,以替换 Spark 默认 catalog spark_catalog。(默认仓库为 Spark 的 spark.sql.warehouse.dir)

目前,仅建议在 Hive metastore 场景下使用 SparkGenericCatalog,Paimon 会从 Spark session 中推断 Hive 配置,你只需要配置 Spark 的 Hive 配置。

spark-sql ... \
    --conf spark.sql.catalog.spark_catalog=org.apache.paimon.spark.SparkGenericCatalog \
    --conf spark.sql.extensions=org.apache.paimon.spark.extensions.PaimonSparkSessionExtensions

使用 SparkGenericCatalog 时,你既可以在该 Catalog 中使用 Paimon 表,也可以使用非 Paimon 表,例如 Spark 的 csv、 parquet、Hive 表等。

创建表​

  • Catalog
  • Generic Catalog
create table my_table (
    k int,
    v string
) tblproperties (
    'primary-key' = 'k'
);
create table my_table (
    k int,
    v string
) USING paimon
tblproperties (
    'primary-key' = 'k'
);

写入表​

  • SQL
  • DataFrame
INSERT INTO my_table VALUES (1, 'Hi'), (2, 'Hello');
-- you can use
Seq((1, "Hi"), (2, "Hello")).toDF("k", "v")
  .write.format("paimon").mode("append").saveAsTable("my_table")

-- or
Seq((1, "Hi"), (2, "Hello")).toDF("k", "v")
  .write.format("paimon").mode("append").save("file:/tmp/paimon/default.db/my_table")

查询表​

  • SQL
  • DataFrame
SELECT * FROM my_table;

/*
1	Hi
2	Hello
*/
-- you can use
spark.read.format("paimon").table("my_table").show()

-- or
spark.read.format("paimon").load("file:/tmp/paimon/default.db/my_table").show()

/*
+---+------+
| k |     v|
+---+------+
|  1|    Hi|
|  2| Hello|
+---+------+
*/

Spark 类型转换​

本节列出 Spark 和 Paimon 之间所有支持的类型转换。 Spark 的所有数据类型都位于 org.apache.spark.sql.types 包中。

MapTypeMapTypefalse

BooleanTypeBooleanTypetrue
ByteTypeTinyIntTypetrue
ShortTypeSmallIntTypetrue
IntegerTypeIntTypetrue
LongTypeBigIntTypetrue
FloatTypeFloatTypetrue
DoubleTypeDoubleTypetrue
StringTypeVarCharType(Integer.MAX_VALUE)true
VarCharType(length)VarCharType(length)true
CharType(length)CharType(length)true
DateTypeDateTypetrue
TimestampTypeLocalZonedTimestamptrue
TimestampNTZType(Spark3.4+)TimestampTypetrue
DecimalType(precision, scale)DecimalType(precision, scale)true
BinaryTypeVarBinaryType, BinaryTypetrue
GeometryType (Spark 4.1)GeometryTypetrue
GeographyType (Spark 4.1)GeographyTypetrue
VariantType(Spark4.0+)VariantTypetrue

由于之前的设计,在 Spark3.3 及以下版本中,Paimon 会将 Paimon 的 TimestampType 和 LocalZonedTimestamp 都映射为 Spark 的 TimestampType,且只对 TimestampType 进行正确处理。

因此,在使用 Spark3.3 及以下版本读取其他引擎(例如 Flink)写入的含 LocalZonedTimestamp 类型的 Paimon 表时,LocalZonedTimestamp 类型的查询结果会带有时区偏移,需要手动调整。

使用 Spark3.4 及以上版本时,所有时间戳类型都可以被正确解析。

原生 GeometryType 和 GeographyType 转换仅在 Spark 4.1 中支持,且仅支持 Spark 识别的 CRS。在生产环境中需显式启用 --conf spark.sql.geospatial.enabled=true;Spark 只在其测试环境中自动启用。Spark 4.1 仅支持 spherical geography 边算法,因此使用 vincenty、thomas、andoyer 或 karney 的 Paimon geography 类型无法转换。Spark 3.x 和 Spark 4.0 会拒绝 Paimon 地理空间列,而不是将其暴露为 BinaryType——否则会丢失 CRS 或边算法。Paimon 不支持混合 SRID 的 Spark 地理空间类型。
