数据类型

数据类型描述了表生态中值的逻辑类型。它可以用来声明操作的输入和/或输出类型。

Paimon 支持的所有数据类型如下:

数据类型 描述
BOOLEAN 布尔值的数据类型,具有(可能)三值逻辑:TRUE、FALSE 和 UNKNOWN。
CHAR
CHAR(n) 		定长字符串的数据类型。

该类型可以使用 CHAR(n) 声明,其中 n 是码点(code point)的数量。n 的取值必须在 1 到 2,147,483,647 之间(含两端)。如果未指定长度,n 等于 1。
VARCHAR
VARCHAR(n)

STRING 		变长字符串的数据类型。

该类型可以使用 VARCHAR(n) 声明,其中 n 是码点(code point)的最大数量。n 的取值必须在 1 到 2,147,483,647 之间(含两端)。如果未指定长度,n 等于 1。

STRING 是 VARCHAR(2147483647) 的同义词。
BINARY
BINARY(n)

 定长二进制字符串(=字节序列)的数据类型。

该类型可以使用 BINARY(n) 声明,其中 n 是字节数。n 的取值必须在 1 到 2,147,483,647 之间(含两端)。如果未指定长度,n 等于 1。
VARBINARY
VARBINARY(n)

BYTES 		变长二进制字符串(=字节序列)的数据类型。

该类型可以使用 VARBINARY(n) 声明,其中 n 是最大字节数。n 的取值必须在 1 到 2,147,483,647 之间(含两端)。如果未指定长度,n 等于 1。

BYTES 是 VARBINARY(2147483647) 的同义词。
GEOMETRY
GEOMETRY(crs) 		以 OGC Well-Known Binary (WKB) 编码的平面几何的数据类型。

可选的 crs 标识坐标参考系统。默认值为 OGC:CRS84。
GEOGRAPHY
GEOGRAPHY(crs)
GEOGRAPHY(crs, algorithm) 		地理对象的数据类型,其边在坐标参考系统的曲面上进行插值,以 OGC Well-Known Binary (WKB) 编码。

默认 crs 为 OGC:CRS84,默认的边插值算法是 spherical。支持的算法有 spherical、vincenty、thomas、andoyer 和 karney。
DECIMAL
DECIMAL(p)
DECIMAL(p, s) 		固定精度和小数位数的十进制数字的数据类型。

该类型可以使用 DECIMAL(p, s) 声明,其中 p 是数字的位数(精度),s 是数字中小数点右边的位数(小数位数)。p 的取值必须在 1 到 38 之间(含两端)。s 的取值必须在 0 到 p 之间(含两端)。p 的默认值为 10,s 的默认值为 0。
TINYINT 1 字节有符号整数的数据类型,取值范围为 -128 到 127。
SMALLINT 2 字节有符号整数的数据类型,取值范围为 -32,768 到 32,767。
INT 4 字节有符号整数的数据类型,取值范围为 -2,147,483,648 到 2,147,483,647。
BIGINT 8 字节有符号整数的数据类型,取值范围为 -9,223,372,036,854,775,808 到 9,223,372,036,854,775,807。
FLOAT 4 字节单精度浮点数的数据类型。

与 SQL 标准相比,该类型不接受参数。
DOUBLE 8 字节双精度浮点数的数据类型。
DATE 由年-月-日组成的日期数据类型,取值范围从 0000-01-01 到 9999-12-31。

与 SQL 标准相比,范围从 0000 年开始。
TIME
TIME(p) 		不带时区的时间数据类型,由 hour:minute:second[.fractional] 组成,最高纳秒精度,取值范围从 00:00:00.000000000 到 23:59:59.999999999。

该类型可以使用 TIME(p) 声明,其中 p 是小数秒部分的位数(精度)。p 的取值必须在 0 到 9 之间(含两端)。如果未指定精度,p 等于 0。
TIMESTAMP
TIMESTAMP(p) 		不带时区的时间戳数据类型,由 年-月-日 hour:minute:second[.fractional] 组成,最高纳秒精度,取值范围从 0000-01-01 00:00:00.000000000 到 9999-12-31 23:59:59.999999999。

该类型可以使用 TIMESTAMP(p) 声明,其中 p 是小数秒部分的位数(精度)。p 的取值必须在 0 到 9 之间(含两端)。如果未指定精度,p 等于 6。
TIMESTAMP WITH LOCAL TIME ZONE
TIMESTAMP(p) WITH LOCAL TIME ZONE 		带本地时区的时间戳数据类型,由 年-月-日 hour:minute:second[.fractional] zone 组成,最高纳秒精度,取值范围从 0000-01-01 00:00:00.000000000 +14:59 到 9999-12-31 23:59:59.999999999 -14:59。

该类型填补了无时区时间戳与必须带时区时间戳之间的空白:它允许根据配置的会话时区来解释 UTC 时间戳。与 int 相互转换时,表示自纪元以来的秒数;与 long 相互转换时,表示自纪元以来的毫秒数。
ARRAY<t> 相同子类型元素组成的数组的数据类型。

与 SQL 标准相比,数组的最大基数(cardinality)不能指定,固定为 2,147,483,647。此外,任何有效类型都支持作为子类型。

该类型可以使用 ARRAY<t> 声明,其中 t 是所包含元素的数据类型。
MAP<kt, vt> 关联数组的数据类型,将键(包括 NULL)映射到值(包括 NULL)。Map 不能包含重复的键;每个键最多只能映射到一个值。

对元素类型没有限制;由用户负责保证唯一性。

该类型可以使用 MAP<kt, vt> 声明,其中 kt 是键元素的数据类型,vt 是值元素的数据类型。
MULTISET<t> 多集(=bag)的数据类型。与 set 不同,它允许具有相同子类型的每个元素出现多个实例。每个唯一值(包括 NULL)都映射到某个重数(multiplicity)。

对元素类型没有限制;由用户负责保证唯一性。

该类型可以使用 MULTISET<t> 声明,其中 t 是所包含元素的数据类型。
ROW<n0 t0, n1 t1, ...>
ROW<n0 t0 'd0', n1 t1 'd1', ...> 		字段序列的数据类型。

一个字段由字段名、字段类型和可选的描述组成。表中一行最具体的类型就是 row 类型。在这种情况下,行中的每一列对应于与该列具有相同序号位置的 row 类型字段。

与 SQL 标准相比,可选的字段描述简化了对复杂结构的处理。

row 类型类似于其他非标准兼容框架中常见的 STRUCT 类型。

该类型可以使用 ROW<n0 t0 'd0', n1 t1 'd1', ...> 声明,其中 n 是字段的唯一名称,t 是字段的逻辑类型,d 是字段的描述。
VARIANT 半结构化数据的数据类型。

专为存储任意半结构化数据而设计,包括 ARRAY、MAP 和标量类型。VARIANT 只能存储键类型为 STRING 的 MAP 类型。

注意:需要 Flink 2.0+ 和 Spark 4.0+。
BLOB 二进制大对象的数据类型。

专为存储大型二进制数据而设计,例如图片、视频、音频文件和其他多模态数据。与内联存储数据的 BYTES 类型不同,BLOB 将大型二进制数据存储在独立的文件中并维护对它们的引用,从而为大对象提供更好的性能。

注意:需要将 'row-tracking.enabled' 和 'data-evolution.enabled' 设置为 true。详见 Blob 类型。
