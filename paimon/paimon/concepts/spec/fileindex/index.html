文件索引

定义 file-index.${index_type}.columns 后，Paimon 会为每个文件创建对应的索引文件。如果索引文件 太小，它会直接存储在 manifest 中，或者存储在数据文件目录中。每个数据文件对应一个索引文件，索引 文件有独立的文件定义，可以包含多种类型、多个列的索引。

索引：BloomFilter​

配置项为：

  • file-index.bloom-filter.columns：指定需要 bloom filter 索引的列。
  • file-index.bloom-filter.<column_name>.fpp：配置误判率。
  • file-index.bloom-filter.<column_name>.items：配置一个数据文件中预期的去重元素数量。

Bloom filter 索引的内容很简单：

  • numHashFunctions 4 bytes int, BIG_ENDIAN
  • bloom filter bytes

该类使用（64 位）long 型哈希，只存储哈希函数数量（一个整数）和位集字节。哈希字节类型 （如 varchar、binary 等）使用 xx hash，数值类型的哈希使用指定的数值哈希。

BloomFilter 支持以下数据类型：

数据类型哈希函数
CharType, VarCharTypexx hash (64-bit)
BinaryType, VarBinaryTypexx hash (64-bit)
TinyIntType, SmallIntType, IntType, BigIntTypeThomas Wang hash
FloatType, DoubleTypeThomas Wang hash (on IEEE 754 bit representation)
DateType, TimeType, TimestampType, LocalZonedTimestampTypeThomas Wang hash

BloomFilter 不支持：BooleanType、DecimalType、VariantType、BlobType、ArrayType、VectorType、MultisetType、MapType、RowType。

索引：Bitmap​

  • file-index.bitmap.columns：指定需要 bitmap 索引的列。
  • file-index.bitmap.<column_name>.index-block-size：配置二级索引块大小，默认值为 16kb。

索引：Range Bitmap​

优势：

  1. 比 bitmap 索引更小。
  2. 适合高基数场景下的点查和范围查询。
  3. 可以用于优化 AND/OR 谓词。（对应的列需要已有 bitmap 索引或 range-bitmap 索引。）
  4. 可以用于优化 topk/bottomk 查询。（目前仅适用于 append-only 表。）

缺点：

  1. 点查的评估可能比 bitmap 索引慢。

配置项：

  • file-index.range-bitmap.columns：指定需要 range-bitmap 索引的列。
  • file-index.range-bitmap.<column_name>.chunk-size：配置 chunk 大小，默认值为 16kb。

表支持使用 range-bitmap 文件索引来优化 EQUALS、RANGE、AND/OR 和 TOPN 谓词。bitmap 和 range-bitmap 文件索引的结果会被合并，并下推到 DataFile 以过滤 rowgroups 和 pages。

在以下查询示例中，class_id 和 score 已经创建了 range-bitmap 文件索引，而分区键 dt 并不是必需的。

优化 EQUALS 谓词：

SELECT * FROM TABLE WHERE dt = '20250801' AND score = 100;

SELECT * FROM TABLE WHERE dt = '20250801' AND score IN (60, 80);

优化 RANGE 谓词：

SELECT * FROM TABLE WHERE dt = '20250801' AND score > 60;

SELECT * FROM TABLE WHERE dt = '20250801' AND score < 60;

优化 AND/OR 谓词：

SELECT * FROM TABLE WHERE dt = '20250801' AND class_id = 1 AND score < 60;

SELECT * FROM TABLE WHERE dt = '20250801' AND class_id = 1 AND score < 60 OR score > 80;

优化 TOPN 谓词：

目前，TOPN 谓词优化不能与其他谓词一起使用，且仅支持 Apache Spark。

SELECT * FROM TABLE WHERE dt = '20250801' ORDER BY score ASC LIMIT 10;

SELECT * FROM TABLE WHERE dt = '20250801' ORDER BY score DESC LIMIT 10;

-- if there are multiple sort keys, the first sort key must be created with range-bitmap.
SELECT * FROM TABLE WHERE dt = '20250801' ORDER BY score ASC, col DESC LIMIT 10;
SELECT * FROM TABLE WHERE dt = '20250801' ORDER BY score DESC, col ASC LIMIT 10;

索引：Bit-Slice Index Bitmap​

注意

已废弃，请使用 range-bitmap 索引替代。

BSI 文件索引是一种数值范围索引，用于加速范围查询，它可以与 bitmap 索引一起使用。

定义 'file-index.bsi.columns'。

BSI 文件索引格式（V1）：

BSI file index format (V1)
+-------------------------------------------------+
| version (1 byte)                                |
+-------------------------------------------------+
| row count (4 bytes int)                         |
+-------------------------------------------------+
| has positive value (1 byte)                     |
+-------------------------------------------------+
| positive BSI serialized (if has positive value) |

+-------------------------------------------------+
| has negative value (1 byte)                     |
+-------------------------------------------------+
| negative BSI serialized (if has negative value) |

+-------------------------------------------------+

BSI 序列化格式（V1）：

+-------------------------------------------------+

BSI 仅支持以下数据类型：TinyIntType、SmallIntType、IntType、BigIntType、DateType、LocalZonedTimestamp、 TimestampType、DecimalType。
