Flink CDC

Flink CDC 是一个面向 Flink 引擎的流式数据集成工具。它允许用户通过 YAML 优雅地描述他们的 ETL 管道 逻辑,并帮助用户自动生成定制化的 Flink 算子并提交作业。

Paimon Pipeline connector 既可以作为 Flink CDC 管道的 Data Source,也可以作为 Data Sink。本文 档介绍如何将 Paimon Pipeline connector 配置为 Data Source。如果你希望将 Paimon 用作 Data Sink,请参考 Flink CDC 的 Paimon Pipeline Connector 文档。

该 connector 能做什么?​

  • 将 Paimon 仓库、数据库或表中的数据同步到 Flink CDC 支持的外部系统
  • 同步 Schema 变更
  • 自动发现源 Paimon 仓库中新创建的表。

如何创建 Pipeline​

从 Paimon 读取数据并写入 Doris 的管道可以按如下方式定义:

source:
  type: paimon
  name: Paimon Source
  database: default
  table: test_table
  catalog.properties.metastore: filesystem
  catalog.properties.warehouse: /path/warehouse

sink:
  type: doris
  name: Doris Sink
  fenodes: 127.0.0.1:8030
  username: root
  password: pass

pipeline:
  name: Paimon to Doris Pipeline
  parallelism: 2

Pipeline Connector 选项​

Key Default Type Description
database
 (none) String Name of the database to be scanned. By default, all databases will be scanned.
table
 (none) String Name of the table to be scanned. By default, all tables will be scanned.
table.discovery-interval
 1 min Duration The discovery interval of new tables. Only effective when database or table is not set.

Catalog 选项​

除了上述 Pipeline connector 选项之外,在 CDC yaml 文件中你还可以配置以 catalog.properties. 开头的选项。例如 catalog.properties.warehouse 或 catalog.properties.metastore。这类 选项会去掉前缀,其余部分作为 catalog 选项。可用 catalog 选项请参阅 配置项一节。

使用注意事项​

  • 主键表的数据更新(-U、+U)会被替换为 -D 和 +I。
  • 不支持删除表。如果你需要从 Paimon 仓库中删除一张表,请在执行删除操作后重启 Flink CDC 作业。作业重启时,它将停止从已删除的表读取数据,而外部系统中的目标表将保持作业停止前的状态不变。
  • 同一张表的数据将由同一个 Flink source 子任务消费。如果不同表之间的数据量差异显著,Flink CDC 作业中可能会观察到数据倾斜导致的性能瓶颈。
  • 如果 CDC 作业已经消费到某张表的最新 Snapshot,而下一个 Snapshot 尚未生成,对该表的监控和消费可能会暂时暂停,直到经过了 continuous.discovery-interval 配置的时间。
