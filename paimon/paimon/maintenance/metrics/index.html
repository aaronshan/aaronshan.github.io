Paimon Metrics

Paimon 构建了一套 metrics 系统来衡量读写行为,例如上一次规划(planning)中扫描了多少个 manifest 文件、上一次提交操作花了多长时间、上一次 compaction 操作删除了多少个文件。

在 Paimon 的 metrics 系统中,metrics 以表粒度更新和上报。

Paimon 指标系统提供了三种类型的指标:Gauge、Counter、Histogram。

  • Gauge:提供某一时刻任意类型的值。
  • Counter:通过递增和递减来计数。
  • Histogram:度量一组值的统计分布,包括最小值、最大值、平均值、标准差和百分位数。

Paimon 已经支持内置 metrics 来衡量 commits、scans、writes、compactions 和 lookups 的操作,这些指标可以桥接到任何支持的计算引擎,如 Flink、Spark 等。

Metrics 列表​

下面是 Paimon 内置 metrics 的列表。它们被归纳为 scan metrics、commit metrics、write metrics、write buffer metrics、blob fetch metrics、compaction metrics 和 lookup metrics 几类。

Scan Metrics​

Metrics 名称 类型 描述
lastScanDuration Gauge 完成上一次 scan 所花费的时间。
scanDuration Histogram 最近几次 scan 耗时的分布。
lastScannedSnapshotId Gauge 上一次 scan 扫描到的 snapshot ID。如果尚未发生 scan,则为 0。
lastScannedManifests Gauge 上一次 scan 中扫描的 manifest 文件数量。
lastScanSkippedTableFiles Gauge 上一次 scan 中跳过的表文件总数。
lastScanResultedTableFiles Gauge 上一次 scan 产出的表文件数量。

Lookup Metrics​

Lookup metrics 适用于本地 partial lookup。它们以 lookup 调用粒度上报。partialLookupRemoteAccessCount 在至少有一个 lookup 文件由于本地缓存不可用而必须从表存储中创建时,将此次 lookup 调用计数一次。它统计的是 lookup 调用次数,而不是单个 OSS 或表存储 I/O 操作的次数。

Metrics 名称 类型 描述
partialLookupCount Counter partial lookup 调用的总次数。
partialLookupRemoteAccessCount Counter 因本地缓存不可用而必须从表存储创建至少一个 lookup 文件的 partial lookup 调用次数。这不是单个 I/O 的计数。

Commit Metrics​

Metrics 名称 类型 描述
lastCommitDuration Gauge 完成上一次 commit 所花费的时间。
commitDuration Histogram 最近几次 commit 耗时的分布。
lastCommitAttempts Gauge 上一次 commit 的尝试次数。
lastTableFilesAdded Gauge 上一次 commit 中新增的表文件数量,包括新创建的数据文件和 compaction 后产出的文件。
lastTableFilesDeleted Gauge 上一次 commit 中删除的表文件数量,来自 compaction 前的文件。
lastTableFilesAppended Gauge 上一次 commit 中追加的表文件数量,即新创建的数据文件。
lastTableFilesCommitCompacted Gauge 上一次 commit 中被 compact 的表文件数量,包括 compaction 前后的文件。
lastChangelogFilesAppended Gauge 上一次 commit 中追加的 changelog 文件数量。
lastChangelogFileCommitCompacted Gauge 上一次 commit 中被 compact 的 changelog 文件数量。
lastGeneratedSnapshots Gauge 上一次 commit 生成的 snapshot 文件数量,可能是 1 个或 2 个 snapshot。
lastDeltaRecordsAppended Gauge 上一次 APPEND 类型 commit 的增量记录数。
lastChangelogRecordsAppended Gauge 上一次 APPEND 类型 commit 的 changelog 记录数。
lastDeltaRecordsCommitCompacted Gauge 上一次 COMPACT 类型 commit 的增量记录数。
lastChangelogRecordsCommitCompacted Gauge 上一次 COMPACT 类型 commit 的 changelog 记录数。
lastPartitionsWritten Gauge 上一次 commit 写入的分区数量。
lastBucketsWritten Gauge 上一次 commit 写入的 bucket 数量。
lastCompactionInputFileSize Gauge 上一次 compaction 输入文件的总大小。
lastCompactionOutputFileSize Gauge 上一次 compaction 输出文件的总大小。
lastCommittedSnapshotId Gauge 上一次 commit 创建的 snapshot ID。如果尚未发生 commit,则为 -1。

Write Buffer Metrics​

Metrics 名称 类型 描述
numWriters Gauge 当前并行度中的 writer 数量。
bufferPreemptCount Gauge 内存被抢占的总次数。
usedWriteBufferSizeByte Gauge 当前已使用的写缓冲区大小(字节)。
totalWriteBufferSizeByte Gauge 配置的写缓冲区总大小(字节)。

Blob Fetch Metrics​

Metrics 名称 类型 描述
blobFetchTotal Counter 写入过程中处理的 blob 拉取结果总数,包括成功的拉取、失败,以及因资源缺失而写入 NULL 的情况。
blobFetchSuccess Counter 成功完成的 blob 拉取总数。
blobFetchSuccessBytes Counter 成功的 blob 拉取写入的总字节数。
blobFetchNullWritten Counter 因 blob 资源缺失或拉取失败而写入 NULL 值的总次数。
blobFetchMissingFileNullWritten Counter 因 blob-write-null-on-missing-file 处理了缺失的 blob 资源而写入 NULL 值的总次数。
blobFetchFailureNullWritten Counter 因 blob-write-null-on-fetch-failure 处理了非 404 的 blob 拉取失败而写入 NULL 值的总次数。
blobFetchFailure Counter 未被写入 NULL 的 blob 拉取失败总数。
blobFetchHttpNotFound Counter HTTP 404 blob 拉取失败总数。
blobFetchHttpClientError Counter 非 404 的 HTTP 4xx blob 拉取失败总数。
blobFetchHttpServerError Counter HTTP 5xx blob 拉取失败总数。
blobFetchHttpOtherError Counter HTTP 状态码不在 4xx 和 5xx 范围内的 blob 拉取失败总数。
blobFetchInvalidUri Counter 因 URI 无效导致的 blob 拉取失败总数。
blobFetchOtherError Counter 既不属于 HTTP 状态类也不属于 URI 无效类的 blob 拉取失败总数。

Compaction Metrics​

Metrics 名称 类型 描述
maxLevel0FileCount Gauge 当前该 task 处理的 level 0 文件最大数量。如果异步 compaction 无法及时完成,该值会变大。
avgLevel0FileCount Gauge 当前该 task 处理的 level 0 文件平均数量。如果异步 compaction 无法及时完成,该值会变大。
compactionThreadBusy Gauge 该 task 中 compaction 线程的最大繁忙度。目前每个并行度只有一个 compaction 线程,因此繁忙度取值范围为 0(空闲)到 100(一直在执行 compaction)。
avgCompactionTime Gauge compaction 线程的平均运行时间,基于记录的 compaction 耗时数据(毫秒)计算。该值表示 compaction 操作的平均时长。值越高说明平均 compaction 时间越长,可能需要性能优化。
compactionCompletedCount Counter 已完成的 compaction 总数。
compactionQueuedCount Counter 排队/运行中的 compaction 总数。
compactionTotalCount Counter compaction 的总数。
maxCompactionInputSize Gauge 该 task compaction 的最大输入文件大小。
avgCompactionInputSize Gauge 该 task compaction 的平均输入文件大小。
maxCompactionOutputSize Gauge 该 task compaction 的最大输出文件大小。
avgCompactionOutputSize Gauge 该 task compaction 的平均输出文件大小。
maxTotalFileSize Gauge 活跃(正在写入)bucket 的最大总文件大小。
avgTotalFileSize Gauge 所有活跃(正在写入)bucket 的平均总文件大小。
maxTotalFileCount Gauge 活跃(正在写入)bucket 的最大文件总数。
avgTotalFileCount Gauge 所有活跃(正在写入)bucket 的平均文件总数。
minAvgFileSize Gauge 所有活跃 bucket 中的最小平均文件大小,按每个 bucket 的总文件大小除以总文件数计算。直接反映是否存在 bucket 小文件问题。仅对主键表上报。
maxSortBufferUsedBytes Gauge 所有活跃 compaction bucket 当前使用的最大 sort buffer 内存(字节)。相对于 maxSortBufferTotalBytes 的高值表示 compaction 期间存在内存压力;可考虑降低 sort-spill-threshold 或减小 sort-spill-buffer-size。
avgSortBufferUsedBytes Gauge 所有活跃 compaction bucket 使用的平均 sort buffer 内存(字节)。
maxSortBufferUtilisationPercent Gauge 所有活跃 compaction bucket 中的最大 sort buffer 利用率(0–100)。持续接近 100 的值表示 sort buffer 池已耗尽,正在或即将发生向磁盘的溢写。
avgSortBufferUtilisationPercent Gauge 所有活跃 compaction bucket 的平均 sort buffer 利用率。

桥接到 Flink​

Paimon 已实现将 metrics 桥接到 Flink 的 metrics 系统,可以由 Flink 上报,metric group 的生命周期由 Flink 管理。

使用 Flink 访问 Paimon 时,请将 <scope>.<infix>.<metric_name> 拼接起来以获得完整的指标标识符,metric_name 可以从 Metrics 列表 中获取。

例如,Flink 作业 insert_word_count 中表 word_count 的指标 lastPartitionsWritten 的标识符为:

localhost.taskmanager.localhost:60340-775a20.insert_word_count.Global Committer : word_count.0.paimon.table.word_count.commit.lastPartitionsWritten。

在 Flink Web-UI 上,进入 committer 算子的 metrics,显示为:

0.Global_Committer___word_count.paimon.table.word_count.commit.lastPartitionsWritten。

信息
  1. 请参考 System Scope 了解 Flink 的 scope
  2. Scan metrics 仅支持 Flink 版本 >= 1.18

Lookup Metrics <host>.taskmanager.<tm_id>.<job_name>.<lookup_operator_name>.<subtask_index> paimon.table.<table_name>.lookup
Commit Metrics <host>.taskmanager.<tm_id>.<job_name>.<committer_operator_name>.<subtask_index> paimon.table.<table_name>.commit

Flink Connector 标准 Metrics​

在使用 Flink 读写时,Paimon 实现了一些关键的 Flink connector 标准 metrics,用于衡量 source 的延迟和 sink 的输出,参见 FLIP-33: Standardize Connector Metrics。已实现的 Flink source / sink metrics 如下。

Source Metrics (Flink)​

Metrics 名称 级别 类型 描述
currentEmitEventTimeLag Flink Source Operator Gauge 记录从 source 发出与文件创建之间的时间差。
currentFetchEventTimeLag Flink Source Operator Gauge 读取数据文件与文件创建之间的时间差。
sourceParallelismUpperBound Flink Source Enumerator Gauge 为自动扩缩容系统推荐的并行度上限。注意:这是推荐值,不是硬性限制。
信息

请注意,如果你在流式查询中指定了 consumer-id,source metrics 的级别将变为 reader 算子,它位于 Monitor 算子之后。

Sink Metrics (Flink)​

Metrics 名称 级别 类型 描述
numBytesOut Table Counter 输出字节总数。
numBytesOutPerSecond Table Meter 每秒输出字节数。
numRecordsOut Table Counter 输出记录总数。
numRecordsOutPerSecond Table Meter 每秒输出记录数。
