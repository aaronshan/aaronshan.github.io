Trino

本文档是在 Trino 中使用 Paimon 的指南。

版本​

Paimon 当前支持 Trino 440。

文件系统​

从 0.8 版本开始,Paimon 的所有动作都共享 Trino 的文件系统,这意味着在使用 trino-paimon 之前,你应该先配置 Trino 文件系统。你可以在 Trino 官方网站上找到如何为 Trino 配置文件系统的信息。

准备 Paimon Jar 文件​

下载

你也可以从源码手动构建 bundled jar。不过,在编译之前需要先完成几个准备步骤:

  • 要从源码构建,请先 克隆 git 仓库。
  • 在本地安装 JDK21,并将 JDK21 配置为全局环境变量。

然后,你可以使用以下命令构建 bundled jar:

mvn clean install -DskipTests

你可以在 ./paimon-trino-<trino-version>/target/paimon-trino-<trino-version>-2.1-SNAPSHOT-plugin.tar.gz 找到 Trino connector jar。

我们使用 hadoop-apache 作为 Hadoop 依赖,默认的 Hadoop 依赖通常同时支持 Hadoop 2 和 Hadoop 3。 如果遇到不支持的场景,你可以指定对应的 Apache Hadoop 版本。

例如,如果你想使用 Hadoop 3.3.5-1,可以使用以下命令构建 jar:

mvn clean install -DskipTests -Dhadoop.apache.version=3.3.5-1

配置 Paimon Catalog​

安装 Paimon Connector​

tar -zxf paimon-trino-<trino-version>-2.1-SNAPSHOT-plugin.tar.gz -C ${TRINO_HOME}/plugin

注意:对于 JDK 21,部署 Trino 时应添加 jvm 参数:--add-opens=java.base/sun.nio.ch=ALL-UNNAMED --add-opens=java.base/java.nio=ALL-UNNAMED

配置​

通过在 etc/catalog 目录下创建 catalog 属性文件来注册 Catalog。例如,创建 etc/catalog/paimon.properties,内容如下,将 paimon connector 挂载为 paimon catalog:

connector.name=paimon
warehouse=file:/tmp/warehouse

如果你使用 HDFS,请选择以下方式之一来配置 HDFS:

  • 设置环境变量 HADOOP_HOME。
  • 设置环境变量 HADOOP_CONF_DIR。
  • 在属性文件中配置 hadoop-conf-dir。

如果你使用 Hadoop 文件系统,仍然可以使用 trino-hdfs 和 trino-hive 来配置。 例如,如果你使用 oss 作为存储,可以参照 Trino 文档 在 paimon.properties 中写入:

hive.config.resources=/path/to/core-site.xml

然后参照 Jindo 文档 配置 core-site.xml。

Kerberos​

使用 KERBEROS 认证时,你可以在属性文件中配置 kerberos keytab 文件。

security.kerberos.login.principal=hadoop-user
security.kerberos.login.keytab=/etc/trino/hdfs.keytab

Keytab 文件必须分发到集群中每个运行 Trino 的节点上。

创建 Schema​

CREATE SCHEMA paimon.test_db;

创建表​

CREATE TABLE paimon.test_db.orders (
    order_key bigint,
    orders_tatus varchar,
    total_price decimal(18,4),
    order_date date
)
WITH (
    file_format = 'ORC',
    primary_key = ARRAY['order_key','order_date'],
    partitioned_by = ARRAY['order_date'],
    bucket = '2',
    bucket_key = 'order_key',
    changelog_producer = 'input'
);

添加列​

CREATE TABLE paimon.test_db.orders (
    order_key bigint,
    orders_tatus varchar,
    total_price decimal(18,4),
    order_date date
)
WITH (
    file_format = 'ORC',
    primary_key = ARRAY['order_key','order_date'],
    partitioned_by = ARRAY['order_date'],
    bucket = '2',
    bucket_key = 'order_key',
    changelog_producer = 'input'
);

ALTER TABLE paimon.test_db.orders ADD COLUMN shipping_address varchar;

查询​

SELECT * FROM paimon.test_db.orders;

时间旅行查询​

-- 读取指定时间戳的快照
SELECT * FROM t FOR TIMESTAMP AS OF TIMESTAMP '2023-01-01 00:00:00 Asia/Shanghai';

-- 读取 id 为 1L 的快照(使用快照 id 作为版本)
SELECT * FROM t FOR VERSION AS OF 1;

-- 读取 tag 'my-tag'
SELECT * FROM t FOR VERSION AS OF 'my-tag';

注意

如果 tag 的名称是数字且等于某个快照 id,VERSION AS OF 语法会优先考虑 tag。例如,如果你有一个基于快照 2 的名为 '1' 的 tag,语句 SELECT * FROM paimon.test_db.orders FOR VERSION AS OF '1' 实际查询的是快照 2 而不是快照 1。

插入​

INSERT INTO paimon.test_db.orders VALUES (.....);

支持:

  • 固定 bucket 的主键表。
  • bucket 为 -1 的非主键表。

Trino 与 Paimon 类型映射​

Trino 数据类型 Paimon 数据类型 原子类型
RowType RowType false
MapType MapType false
ArrayType ArrayType false
BooleanType BooleanType true
TinyintType TinyIntType true
SmallintType SmallIntType true
IntegerType IntType true
BigintType BigIntType true
RealType FloatType true
DoubleType DoubleType true
CharType(length) CharType(length) true
VarCharType(VarCharType.MAX_LENGTH) VarCharType(VarCharType.MAX_LENGTH) true
VarCharType(length) VarCharType(length), length is less than VarCharType.MAX_LENGTH true
DateType DateType true
TimestampType TimestampType true
DecimalType(precision, scale) DecimalType(precision, scale) true
VarBinaryType(length) VarBinaryType(length) true
TimestampWithTimeZoneType LocalZonedTimestampType true

临时目录​

Paimon 会将一些 jar 解压到临时目录用于 codegen。默认情况下,Trino 使用 '/tmp' 作为临时目录,但 '/tmp' 可能会被定期清理。

你可以在 Trino 启动时配置以下环境变量:

-Djava.io.tmpdir=/path/to/other/tmpdir

让 Paimon 使用一个安全的临时目录。
