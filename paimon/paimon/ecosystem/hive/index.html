Hive

本文档是在 Hive 中使用 Paimon 的指南。

版本​

Paimon 当前支持 Hive 3.1、2.3、2.2、2.1 和 2.1-cdh-6.3。

执行引擎​

Paimon 当前支持 Hive 读取使用 MR 和 Tez 执行引擎,Hive 写入使用 MR 执行引擎。 注意:如果你使用 beeline,请重启 Hive 集群。

安装​

下载对应版本的 jar 文件。

Jar
Hive 3.1paimon-hive-connector-3.1-2.1-SNAPSHOT.jar
Hive 2.3paimon-hive-connector-2.3-2.1-SNAPSHOT.jar
Hive 2.2paimon-hive-connector-2.2-2.1-SNAPSHOT.jar
Hive 2.1paimon-hive-connector-2.1-2.1-SNAPSHOT.jar
Hive 2.1-cdh-6.3paimon-hive-connector-2.1-cdh-6.3-2.1-SNAPSHOT.jar

你也可以从源码手动构建 bundled jar。

要从源码构建,请先 克隆 git 仓库。

使用以下命令构建 bundled jar: mvn clean install -DskipTests

你可以在 ./paimon-hive/paimon-hive-connector-<hive-version>/target/paimon-hive-connector-<hive-version>-2.1-SNAPSHOT.jar 找到 Hive connector jar。

有几种方式可以将该 jar 添加到 Hive:

  • 你可以在 Hive 根目录下创建 auxlib 文件夹,并将 paimon-hive-connector-2.1-SNAPSHOT.jar 拷贝到 auxlib 中。
  • 你也可以将该 jar 拷贝到 Hive 可访问的路径,然后使用 add jar /path/to/paimon-hive-connector-2.1-SNAPSHOT.jar 在 Hive 中启用 Paimon 支持。注意,不推荐这种方式。如果你使用 MR 执行引擎并运行 join 语句,可能会遇到异常 org.apache.hive.com.esotericsoftware.kryo.kryoexception: unable to find class。

注意:

  • 如果你使用 HDFS:
    • 确保已设置环境变量 HADOOP_HOME 或 HADOOP_CONF_DIR。
    • 你可以设置 paimon.hadoop-load-default-config =false 来禁止从 core-default.xml、hdfs-default.xml 加载默认值,这可能会让 split 的体积更小。
  • 在使用 Hive CBO 时,可能会导致一些不正确的查询结果,例如对 struct 类型使用 not null 谓词查询,你可以通过 set hive.cbo.enable=false; 命令禁用 CBO。

Hive SQL:访问已在 Hive Metastore 中的 Paimon 表​

在 Hive CLI 中运行以下 Hive SQL 来访问已创建的表。

-- 假设 paimon-hive-connector-<hive-version>-2.1-SNAPSHOT.jar 已经在 auxlib 目录中。
-- 列出 Hive 中的表
-- (如果默认不在 "default" 数据库,你可能需要先切换过去)

SHOW TABLES;

/*
OK
test_table
*/

-- 从 test_table 读取记录

SELECT a, b FROM test_table ORDER BY a;

/*
OK
1	Table
2	Store
*/

-- 向测试表插入记录
-- 限制:
-- 只支持 INSERT INTO,不支持 INSERT OVERWRITE
-- 建议写入非主键表
-- 写入主键表可能会产生大量小文件

INSERT INTO test_table VALUES (3, 'Paimon');

SELECT a, b FROM test_table ORDER BY a;

/*
OK
1	Table
2	Store
3	Paimon
*/

-- 时间旅行

SET paimon.scan.snapshot-id=1;
SELECT a, b FROM test_table ORDER BY a;
/*
OK
1	Table
2	Store
3	Paimon
*/
SET paimon.scan.snapshot-id=null;

Hive SQL:创建新的 Paimon 表​

你可以在 Hive 中创建新的 Paimon 表。在 Hive CLI 中运行以下 Hive SQL。

-- 假设 paimon-hive-connector-2.1-SNAPSHOT.jar 已经在 auxlib 目录中。
-- 创建一张新的 Paimon 表。

SET hive.metastore.warehouse.dir=warehouse_path;

CREATE TABLE hive_test_table(
    a INT COMMENT 'The a field',
    b STRING COMMENT 'The b field'
)
STORED BY 'org.apache.paimon.hive.PaimonStorageHandler';

Hive SQL:通过外部表访问 Paimon 表​

要访问已有的 Paimon 表,你也可以在 Hive 中将它们注册为外部表。在 Hive CLI 中运行以下 Hive SQL。

-- 假设 paimon-hive-connector-2.1-SNAPSHOT.jar 已经在 auxlib 目录中。
-- 使用上一节创建的 test_table。
-- 创建外部表时,不需要指定任何列或表属性。
-- 只需将 location 指向表的路径即可。

CREATE EXTERNAL TABLE external_test_table
STORED BY 'org.apache.paimon.hive.PaimonStorageHandler'
LOCATION '/path/to/table/store/warehouse/default.db/test_table';
    
-- 除了上面设置 location 的方式,你也可以将 location 设置放在 TBProperties 中,
-- 以避免 Hive 在创建表时通过自己的文件系统访问 Paimon 的 location。
-- 这种方式在使用对象存储(如 S3)的场景下很有效。

CREATE EXTERNAL TABLE external_test_table
STORED BY 'org.apache.paimon.hive.PaimonStorageHandler'
TBLPROPERTIES (
 'paimon_location' ='s3://xxxxx/path/to/table/store/warehouse/default.db/test_table'
);

-- 从 external_test_table 读取记录

SELECT a, b FROM external_test_table ORDER BY a;

/*
OK
1	Table
2	Store
*/

-- 向测试表插入记录

INSERT INTO external_test_table VALUES (3, 'Paimon');

SELECT a, b FROM external_test_table ORDER BY a;

/*
OK
1	Table
2	Store
3	Paimon
*/
