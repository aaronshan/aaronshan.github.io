PyTorch

读取​

这需要安装 torch。

你可以将全部数据读入一个 torch.utils.data.Dataset 或 torch.utils.data.IterableDataset:

from torch.utils.data import DataLoader

table_read = read_builder.new_read()
dataset = table_read.to_torch(splits, streaming=True, prefetch_concurrency=2)
dataloader = DataLoader(
    dataset,
    batch_size=2,
    num_workers=2,  # 读取数据的并发度
    shuffle=False
)

# 从 dataloader 收集所有数据
for batch_idx, batch_data in enumerate(dataloader):
    print(batch_data)

# 输出:
#   {'user_id': tensor([1, 2]), 'behavior': ['a', 'b']}
#   {'user_id': tensor([3, 4]), 'behavior': ['c', 'd']}
#   {'user_id': tensor([5, 6]), 'behavior': ['e', 'f']}
#   {'user_id': tensor([7, 8]), 'behavior': ['g', 'h']}

当 streaming 参数为 true 时,将以迭代方式读取。当它为 false 时, 符合条件的 data-evolution 读取会按行 ID 惰性获取每个 DataLoader 批次; 其他读取会在内存中保留一个 Arrow 表,用于 map 风格的访问。

prefetch_concurrency(默认值:1):在流式行模式下,控制每个 DataLoader worker 的读取线程数。在非流式模式下无效。

分布式分片​

流式读取会将 split 在 DDP rank 和 DataLoader worker 之间分片:

def main():
    dataset = table_read.to_torch(
        splits,
        streaming=True,
        auto_detect_rank=True,
    )
    dataloader = DataLoader(
        dataset,
        batch_size=32,
        num_workers=2,
        multiprocessing_context="spawn",
    )

    with model.join():
        for batch in dataloader:
            train(batch)


if __name__ == "__main__":
    main()

自动 rank 分片是可选启用的。只有当每个 rank 都从同一个快照接收到 相同且有序的完整 split 时才启用它;对于已由应用完成分片的 split, 请保持禁用。 自动检测使用默认进程组。对于子组(subgroup)DDP,请在创建 DataLoader 之前从对应 group 解析上下文:

import torch.distributed as dist

dataset = table_read.to_torch(
    splits,
    streaming=True,
    sharding_rank=dist.get_rank(ddp_group),
    sharding_world_size=dist.get_world_size(ddp_group),
)

使用多 worker DDP 时,请使用 spawn(或 forkserver),并通过 if __name__ == "__main__": 保护的入口点创建和迭代 DataLoader。 由于各 split 大小不同,某个 rank 可能会收到更少的行;join() 可以在不丢失、不重复任何一行的前提下保持 DDP 集合通信对齐。 当存在多个活跃 rank 时,可能截断输入的 limit 会被拒绝。

批式流读取​

对于面向批次的训练,可以让流式数据集直接产出批次:

dataset = table_read.to_torch(
    splits,
    streaming=True,
    batch_format="torch",
    batch_size=1024,
)
dataloader = DataLoader(dataset, batch_size=None, num_workers=2)

for batch in dataloader:
    train(batch["features"], batch["label"])

batch_format="pyarrow" 会产出 PyArrow RecordBatch 对象; batch_format="torch" 会产出张量字典。默认的 Tensor 转换器支持非空的数值、布尔和数值型定长列表(fixed-size-list) 列。对于其他类型或自定义转换,请使用 to_tensor_fn。

省略 batch_size 可保留读取器的原生批次。否则,批次会被 合并或切分到请求的大小。使用 DataLoader(batch_size=None) 可以 禁用第二次批处理步骤。批式流读取不支持 shuffle=True。 数值型张量可能共享只读的 Arrow buffer;在进行原地修改前请先克隆。 批式格式目前要求 prefetch_concurrency=1。

视频帧描述符​

对于多模态帧表,请使用更高层的 scan API:

dataset = (
    frames.scan()
    .select(["episode_id", "state", "action", "video"])
    .to_torch(streaming=True)
)

.video 列产出序列化的 VideoFrameDescriptor 值,其内嵌的帧序号 使帧映射无需存放在普通数据文件中。使用 pypaimon.multimodal.VideoFrameCollator 作为 DataLoader 的 collate_fn,可以打开物理视频区间并按 worker 缓存解码器会话。写入路径 和完整的解码器示例请参见 多模态 API:视频帧存储。

文件格式元数据缓存​

可复用的 PyArrow Dataset 元数据会在多次读取之间缓存。可在 catalog 配置项中配置其估计大小上限:

catalog = CatalogFactory.create({
    "warehouse": "file:///path/to/warehouse",
    "file-format.metadata-cache.max-size": "50 mb",
})
table = catalog.get_table("database.table")
read_builder = table.new_read_builder()

默认上限为 50 MB;设置为 0 b 可禁用并清空缓存。该缓存是每个 进程本地的,对于配合 DataLoader(..., persistent_workers=True) 复用的 worker 尤为有益。缓存采用保守的单条内存估算和内置的条目数 保护机制;实际的原生 PyArrow 内存占用仍可能更高。该缓存假定 Paimon 数据文件是不可变的。

Shuffle​

PyPaimon 支持面向 PyTorch IterableDataset 的流式 shuffle。shuffle 流水线可以由三层组成:

  1. Chunk shuffle:在 scan 规划阶段将文件切分为行块(row chunk), 并对生成的 chunk split 做 shuffle。通过 TableScan.with_chunk_shuffle(seed, chunk_size) 启用。
  2. Split interleave:在每个 DataLoader worker 内部以轮询 (round-robin)顺序从多个 split 读取。
  3. Buffer shuffle:在行被产出给 PyTorch 之前, 应用蓄水池(reservoir)风格的行 shuffle 缓冲区。

Chunk shuffle 是面向 append 表(包括 Data Evolution append 表)的 scan 规划特性。对于 Data Evolution 表,chunk shuffle 在按行 ID 区间 切分时,会保持按行 ID 对齐的数据文件和 sidecar 文件在一起。chunk shuffle 应与支持随机访问的文件格式一起使用。目前支持随机访问的 文件格式有 Lance、Vortex、Row 和 Blob。主键表和 deletion-vector 扫描不受 with_chunk_shuffle 支持。

第二层和第三层是 Dataset 特性。它们作用于你传给 to_torch 的 split,因此既可用于普通 split,也可用于经过 chunk shuffle 的 split。

仅使用 Dataset Shuffle​

当普通 scan split 已经足够,你只想要 split interleave 加上行 buffer shuffle 时使用:

from torch.utils.data import DataLoader

table_scan = read_builder.new_scan()
table_read = read_builder.new_read()
splits = table_scan.plan().splits()

dataset = table_read.to_torch(
    splits,
    streaming=True,
    shuffle=True,
    seed=42,
    buffer_size=1000,
    max_buffer_input_splits=10,
)

dataloader = DataLoader(
    dataset,
    batch_size=32,
    num_workers=2,
    shuffle=False,
)

buffer_size 控制行 shuffle 缓冲区。更大的值可以更好地 近似全局 shuffle,代价是占用更多内存。如果 max_buffer_input_splits 为 1,则跳过 split interleave, 只应用 buffer shuffle。shuffle=True 要求 streaming=True, 且不支持 prefetch_concurrency > 1。

使用全部三层​

对于 append 表,在 scan 规划阶段启用 chunk shuffle, 然后在转换为 PyTorch 时启用 Dataset shuffle:

from torch.utils.data import DataLoader

seed = 42

table_scan = read_builder.new_scan().with_chunk_shuffle(
    seed=seed,
    chunk_size=1000,
)
table_read = read_builder.new_read()
splits = table_scan.plan().splits()

dataset = table_read.to_torch(
    splits,
    streaming=True,
    shuffle=True,
    seed=seed,
    buffer_size=1000,
    max_buffer_input_splits=10,
)

dataloader = DataLoader(
    dataset,
    batch_size=32,
    num_workers=2,
    shuffle=False,
)

如果你希望每个训练 epoch 使用不同的 buffer-shuffle 顺序, 请在为新 epoch 创建或迭代 DataLoader 之前调用 dataset.set_epoch(epoch)。
