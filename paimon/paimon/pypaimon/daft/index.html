Daft

Daft 是一个面向 Python 的分布式 DataFrame 引擎。 另请参阅 Daft Paimon connector 文档。

这需要安装 daft:

pip install 'pypaimon[daft]'

要在 Ray 上执行 Daft 计划,请同时安装两个 extras:

pip install 'pypaimon[daft,ray]'

pypaimon.daft 暴露了顶层的 read_paimon / write_paimon API, 可直接接收表标识符和 catalog 配置。

读取​

read_paimon(推荐)​

from pypaimon.daft import read_paimon

df = read_paimon(
    "database_name.table_name",
    catalog_options={"warehouse": "/path/to/warehouse"},
)

df.show()

read_paimon 会自己打开 catalog,并在一次调用中解析表。

返回的 DataFrame 是惰性的。使用标准的 Daft 操作进行过滤、 投影和 limit —— 它们会通过 Daft 的 DataSource 协议自动下推 到 Paimon scan:

import daft

df = read_paimon(
    "database_name.table_name",
    catalog_options={"warehouse": "/path/to/warehouse"},
)

# 过滤下推(分区裁剪 + 文件级跳过)
df = df.where(daft.col("dt") == "2024-01-01")

# 投影下推(只从磁盘读取请求的列)
df = df.select("id", "name")

# Limit 下推
df = df.limit(100)

df.show()

时间旅行:

# 读取指定快照。
df = read_paimon(
    "database_name.table_name",
    catalog_options={"warehouse": "/path/to/warehouse"},
    snapshot_id=42,
)

# 读取打了 tag 的快照。
df = read_paimon(
    "database_name.table_name",
    catalog_options={"warehouse": "/path/to/warehouse"},
    tag_name="release-2026-04",
)

# 读取不晚于某时间戳的最新快照。
# 接受 int(epoch 毫秒)、datetime 或 "YYYY-MM-DD HH:MM:SS" 字符串。
df = read_paimon(
    "database_name.table_name",
    catalog_options={"warehouse": "/path/to/warehouse"},
    timestamp="2026-07-09 10:00:00",
)

snapshot_id、tag_name 和 timestamp 互斥。

参数:

  • table_identifier:完整表名,例如 "db_name.table_name"。
  • catalog_options:转发给 CatalogFactory.create() 的 kwargs, 例如 {"warehouse": "/path/to/warehouse"}。
  • snapshot_id:可选,时间旅行到的快照 id。与 tag_name 和 timestamp 互斥。
  • tag_name:可选,时间旅行到的 tag 名。与 snapshot_id 和 timestamp 互斥。
  • timestamp:可选,时间旅行到不晚于该时间戳的最新快照。 接受 int(epoch 毫秒)或 datetime(两者都会映射为 scan.timestamp-millis),或 str,例如 "2026-07-09 10:00:00" (映射为 scan.timestamp)。不带时区的 datetime 按本地时区解释。 与 snapshot_id 和 tag_name 互斥。
  • io_config:可选,用于访问对象存储的 Daft IOConfig。 如果为 None,将从 catalog 配置中推断。

对于对象存储上的表,凭证会自动从 catalog 配置中推断, 你也可以显式传入 IOConfig:

from daft.io import IOConfig, S3Config

df = read_paimon(
    "my_db.my_table",
    catalog_options={
        "warehouse": "s3://my-bucket/warehouse",
        "fs.s3.accessKeyId": "...",
        "fs.s3.accessKeySecret": "...",
    },
)
df.show()

特性:

  • Parquet 格式的 append-only 表使用 Daft 原生高性能 Parquet 读取器。
  • 需要 LSM 合并的主键表回退到 pypaimon 内置读取器。
  • 支持分区裁剪、谓词下推、投影下推和 limit 下推。

写入​

write_paimon(推荐)​

import daft
from pypaimon.daft import write_paimon

df = daft.from_pydict({
    "id": [1, 2, 3],
    "name": ["alice", "bob", "charlie"],
    "dt": ["2024-01-01", "2024-01-01", "2024-01-01"],
})

write_paimon(
    df,
    "database_name.table_name",
    catalog_options={"warehouse": "/path/to/warehouse"},
)

write_paimon 会自己打开 catalog、解析表,并通过 Daft 的 DataSink API 提交写入。

覆盖模式:

write_paimon(
    df,
    "database_name.table_name",
    catalog_options={"warehouse": "/path/to/warehouse"},
    mode="overwrite",
)

对于非分区表,覆盖会替换整个表内容。对于分区表,覆盖默认遵循 Paimon 的动态分区覆盖语义:只有输入 DataFrame 中出现的分区会被 替换,输入中不存在的已有分区保持不变。

参数:

  • df:要写入的 Daft DataFrame。
  • table_identifier:完整表名,例如 "db_name.table_name"。
  • catalog_options:转发给 CatalogFactory.create() 的 kwargs。
  • mode:写入模式 —— "append"(默认)或 "overwrite"。

在 Ray 上运行 Daft​

pypaimon.daft 可与 Daft 的 Ray runner 配合工作。请在进程中 第一次 Daft 执行之前配置 runner:

import daft
import ray
from daft import runners
from pypaimon.daft import read_paimon, write_paimon

ray.init()  # 使用 address="auto" 连接已有的 Ray 集群
runners.set_runner_ray()

df = daft.from_pydict({
    "id": [1, 2, 3],
    "name": ["alice", "bob", "charlie"],
    "dt": ["2024-01-01", "2024-01-01", "2024-01-02"],
})

write_paimon(
    df,
    "database_name.table_name",
    catalog_options={"warehouse": "/path/to/warehouse"},
)

result = (
    read_paimon(
        "database_name.table_name",
        catalog_options={"warehouse": "/path/to/warehouse"},
    )
    .where(daft.col("dt") == "2024-01-01")
    .select("id", "name")
)

result.show()

当你的应用以 Daft DataFrame 编写,并希望由 Daft 在 Ray 上 调度执行时,使用 pypaimon.daft。当你的应用直接读写 Ray Dataset 时,改用 pypaimon.ray。

读取 Blob 列​

包含 BLOB 列的表(见 Blob 存储)可以通过 Daft 读取。 Blob 列以 daft.File 引用的形式返回 —— 实际的字节在你 显式读取之前不会被加载。

Daft 内置 connector 尚不支持 blob 惰性加载

daft.read_paimon() 目前会在 scan 阶段立即读取 blob 数据, 对 blob 列忽略列裁剪和过滤下推。 如需 blob 惰性加载,请改用 from pypaimon.daft import read_paimon。

惰性加载​

通过 pypaimon.daft 读取 blob 表时,connector 会在内部 自动启用描述符模式。Blob 列在 DataFrame 中以 daft.File 引用的形式出现 —— 此时不会从存储中获取任何字节。 实际的 I/O 只发生在你在 UDF 中调用 file.open() 时, 并且只针对通过了先前过滤的行:

import daft
from daft import col
from pypaimon.daft import read_paimon

df = read_paimon(
    "my_db.image_table",
    catalog_options={"warehouse": "/path/to/warehouse"},
)

# 过滤在读取任何 blob 字节之前执行。
df = df.where(col("id") < 100)

# file.length 从描述符返回 blob 大小(零 I/O)。
@daft.func(return_dtype=daft.DataType.int64())
def file_length(f: daft.File) -> int | None:
    return None if f is None else f.length

result = df.with_column("size", file_length(col("image")))
result.show()

读取 blob 内容​

使用 read_blob 将 blob File 列读为 binary 字节。它会 并发读取 blob,因此比逐行 file.open() 循环快得多:

from daft import col
from pypaimon.daft import read_paimon, read_blob

catalog_options = {"warehouse": "oss://my-bucket/warehouse"}
table = "my_db.image_table"

df = read_paimon(table, catalog_options)
df = df.where(col("id") < 100)  # 在读取字节前先过滤

result = df.select(
    col("id"),
    read_blob(col("image"), catalog_options, table).alias("image_bytes"),
)
result.show()

使用 max_concurrency(默认 64)调节并发度。

使用 open_blob 进行流式 / 部分读取​

对于大型 blob(视频、模型权重)等不希望全部加载到内存的 场景,使用 open_blob 获取可寻址的流:

import daft
from daft import col
from pypaimon.daft import read_paimon, open_blob

catalog_options = {"warehouse": "oss://my-bucket/warehouse"}
table = "my_db.image_table"

df = read_paimon(table, catalog_options)

@daft.func(return_dtype=daft.DataType.binary())
def first_4k(file: daft.File) -> bytes | None:
    if file is None:
        return None
    with open_blob(file, catalog_options, table) as f:
        return f.read(4096)

result = df.with_column("header", first_4k(col("image")))

open_blob 是 file.open() 的直接替代,用于流式读取单个 大型 blob。它每次调用读取一个 blob,因此整列批量读取请优先 使用 read_blob。

Catalog 抽象​

Paimon catalog 可以集成到 Daft 统一的 Catalog / Table 接口中:

import pypaimon
from pypaimon.daft import PaimonCatalog

inner = pypaimon.CatalogFactory.create({"warehouse": "/path/to/warehouse"})
catalog = PaimonCatalog(inner, name="my_paimon")

# 浏览
catalog.list_namespaces()
catalog.list_tables()

# 通过 catalog 读写
table = catalog.get_table("my_db.my_table")
df = table.read()
table.append(df)
table.overwrite(df)

你也可以直接包装单个表:

from pypaimon.daft import PaimonTable

inner_table = inner.get_table("my_db.my_table")
table = PaimonTable(inner_table)
df = table.read()

创建表​

import daft
from daft.io.partitioning import PartitionField

schema = daft.from_pydict({"id": [1], "name": ["a"], "dt": ["2024-01-01"]}).schema()
dt_field = schema["dt"]
partition_fields = [PartitionField.create(dt_field)]

table = catalog.create_table(
    "my_db.new_table",
    schema,
    partition_fields=partition_fields,
)

# 主键表
table = catalog.create_table(
    "my_db.pk_table",
    schema,
    properties={"primary_keys": ["id", "dt"]},
    partition_fields=partition_fields,
)
