ubuntu 64位下安装wps

本文介绍了在Ubuntu 64位系统中如何安装WPS的详细步骤，包括从官网下载软件，处理安装过程中遇到的字体错误，以及如何下载并安装缺失字体以成功启动WPS。

Aaron2014-08-041 分钟阅读开发配置 · Ubuntu · CSDN

首先，去官网 下载 wps。地址：http://community.wps.cn/download/

然后 切换 到下载目录，执行如下命令：

$ sudo apt-get install ia32-libs*

然后执行安装命令：

$ sudo dpkg -i --force-architecture  wps-office_8.1.0.3724~b1p2_i386.deb

会报如下错误：

没关系，使用如下命令修正：

$ sudo apt-get -f install

然后等待安装完成即可。安装完成后效果如下：

不过，此时会有如下错误：

现在，只需要在下载链接处下载对应 字体 ，然后解压到~/.fonts目录下，再重启wps即可。
