Ubuntu12.04安装深度音乐

本文介绍如何解决在Deepin系统中安装Deepin音乐播放器遇到的依赖问题，并提供正确的安装步骤。

Aaron2014-07-251 分钟阅读开发配置 · Ubuntu · CSDN

在以下地址 下载 最新的deb包（注意，是.deb格式的文件），按照你系统的位数选择32位或64位。

下载 python -deepin-utils：http://packages.linuxdeepin.com/deepin/pool/main/d/deepin-utils/

下载deepin-ui： http://packages.linuxdeepin.com/deepin/pool/main/d/deepin-ui/

下载 deepin -music-player：http://packages.linuxdeepin.com/deepin/pool/main/d/deepin-music-player/

下载完成后放在同一个新建的 文件夹 中，比如deepin，然后执行安装语句：

sudo dpkg -i *.deb

会出现如下错误：

Selecting previously unselected package deepin-music-player.
(正在读取数据库 ... 系统当前共安装有 291519 个文件和目录。)
正在解压缩 deepin-music-player (从 deepin-music-player_1.1+20140703161042~6239766e2c_all.deb) ...
正预备替换 deepin-ui 1+git20131108164648~e369b783df (使用 deepin-ui_1.1+20140703172225~f4d58791c4_all.deb) ...
正在解压缩将用于更替的包文件 deepin-ui ...
正预备替换 python-deepin-utils 0.0.1-1+git20131108164844~7868ec55e9 (使用 python-deepin-utils_0.0.2+20140703165416~8aaf2a6f00_amd64.deb) ...
正在解压缩将用于更替的包文件 python-deepin-utils ...
dpkg：依赖关系问题使得 deepin-music-player 的配置工作不能继续：
 deepin-music-player 依赖于 python-mutagen (>= 1.8)；然而：
  未安装软件包 python-mutagen。
 deepin-music-player 依赖于 python-pyquery；然而：
  未安装软件包 python-pyquery。
 deepin-music-player 依赖于 gstreamer0.10-plugins-bad-multiverse；然而：
  未安装软件包 gstreamer0.10-plugins-bad-multiverse。
 deepin-music-player 依赖于 python-cddb；然而：
  未安装软件包 python-cddb。
 deepin-music-player 依赖于 python-keybinder；然而：
  未安装软件包 python-keybinder。
dpkg：处理 deepin-music-player (--install)时出错：
 依赖关系问题 - 仍未被配置
正在设置 python-deepin-utils (0.0.2+20140703165416~8aaf2a6f00) ...
正在设置 deepin-ui (1.1+20140703172225~f4d58791c4) ...
正在处理用于 hicolor-icon-theme 的触发器...
正在处理用于 bamfdaemon 的触发器...
Rebuilding /usr/share/applications/bamf.index...
正在处理用于 desktop-file-utils 的触发器...
正在处理用于 gnome-menus 的触发器...
在处理时有错误发生：
 deepin-music-player

没有关系。只要再执行如下语句安装依赖即可：

sudo apt-get -f install
