菜鸟学Python-安装与配置环境

本文详细介绍了在Windows和Ubuntu环境下安装Python的方法，以及如何使用Eclipse结合PyDev插件作为强大的Python开发环境。包括从安装Python、配置Eclipse到创建Python项目和编写代码的全过程。

最近开始学习 Python ，为整理思路，特此撰文以记之。

1、一些基础知识

要学习一门编程语言，安装其开发工具自然是必不可少的事情之一。本人此次基于windowshe和 linux （ubuntu）学习Python，所以其开发工具的安装也只论述windows和ubuntu环境下的安装过程。

windows 环境下安装：

（1）打开浏览器，输入www.python.org并点击Download链接。

（2）在此可以看到Python 2.7或Python3.3或其他版本的Python Windows Installer。点击 下载 。

（3）双击下载的.msi文件，然后按照安装流程进行安装。

（4）安装成功后，即可选择程序->Python2.7/Python3.3->IDLE（Python GUI），打开Python的开发环境。如下图所示：

ubuntu 下安装：

在Ctrl+Alt+t打开终端，输入命令：apt-get install python即可。安装后可在终端输入python，如下图：

或许你已经习惯了在Visual studio/CodeBlocks中开发C/C++，在 Eclipse /Netbeans中开发Java。理所应当的，我们也可以选择使用IDE开发环境开发Python程序。本文介绍Eclipse+Python的配置工作。首先介绍Eclipse插件PyDev的一些基本知识。

PyDev for Eclipse 是一个功能强大且易用的 Eclipse Python IDE 插件。本文将向读者介绍 PyDev 开源项目及其安装配置方法，并在此基础上详细介绍如何利用 PyDev 插件把 Eclipse 变为功能强大且易用的 Python IDE，如何利用其进行 Python 程序的开发和调试。通过本文，读者不仅可以了解 PyDev 这个开源项目，更能深入了解如何应用 PyDev插件把 Eclipse 当作 Python IDE 进行 Python 应用程序的开发和调试。

其次介绍它的安装过程（在此之前需要安装Eclipse+JDK+Python编译器）。下载Eclipse下开发Python的 插件 PyDev，目前版本是2.7.1。http://sourceforge.net/projects/pydev/
