Ubuntu12.04中安装deepin-screeshot 2.0

本文介绍如何在Linux环境下使用Deepin截图工具deepin-screeshot进行高效截屏，包括解决依赖问题、下载安装步骤以及快捷键配置等关键操作。

Aaron2012-11-201 分钟阅读开发配置 · ubuntu · Ubuntu · CSDN

在 linux 下之前一直没有找到合适的截屏工具，截屏颇为麻烦。尤其在使用Web QQ的时候更是如此。虽说chrome有浏览器截屏插件，但还是不给力。今天发现个好东西。不过网上的教程明显过时了，特此更新一下。

1、在安装 deepin -screeshot 2.0之前需要解决一下软件依赖关系。在终端输入如下命令：

sudo apt- get install python-xlib

sudo apt-get install python -webkit

sudo apt-get install python-wnck

2、 下载 deepin-ui_1+git201211141021_i386.deb和deepin-screenshot_2.0+git201210081328_all.deb。

注：如果链接失效，在 浏览器 中输入http://packages.linuxdeepin.com/deepin/pool/main/d/，查找deepin- ui 和deepin-screenshot目录并打开，在相应的目录中下载最新出的相应deb包。

3、切换到下载目录，执行如下语句。（注意，首先得安装deepin-ui_1+git201211141021_i386.deb）因为deepin-screenshot_2.0+git201210081328_all.deb依赖它）

sudo dpkg -i deepin-ui_1+git201211141021_i386.deb

sudo dpkg -i deepin-screenshot_2.0+git201210081328_all.deb

4、配置快捷方式。选择System Setting（系统设置）-> Keyboard（键盘）-> ShortCuts（快捷键），点击底下的”+“，在Name（名字）一栏输入名字，如：sreenshot。在 Command （命令）一栏输入deepin-screenshot。然后选中sreenshot，按下Ctrl+Alt+A，即可将Ctrl+Alt+A设定为截屏的快捷键。
