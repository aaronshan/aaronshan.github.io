Ubuntu 12.04下安装QQ 2012

本文介绍如何在Ubuntu系统中通过Wine安装并运行QQ。首先安装Wine，再通过winetricks安装必要的Windows DLL和组件，最后下载并安装QQ客户端。

Aaron2012-11-091 分钟阅读开发配置 · linux · qq · ubuntu · CSDN

Ubuntu 用着什么都好，就是缺了QQ。没办法，周围人都在用它作为聊天工具，所以只能想办法安装一个。企鹅的linux版QQ已经很久没有更新了，目前其他linux版的QQ功能，稳定性都有待提高。所以，基于wine安装是目前比较好的解决方案了。

第一步：Ctrl+Alt+t 打开终端，输入以下命令：sudo apt- get install wine。经过一段时间，就可以安装好。需要注意的是安装过程中会出现软件包配置的图形界面，需要使用左键或右键切换，选择OK，才能进行下一步的安装公工作。

第二步：经过上一步，我们已经安装好了wine。但是我们还需要安装一些 Windows 的DLL和组建，以支持QQ的正常运行。这一步我们完全可以通过wine提供的图形界面来完成。

在终端输入winetricks，会打开一个图形窗口：

选择OK进入下一步，选择安装Windows DLLs和常用组件：

此时需要选择一些常用的组件保证QQ和其他Windows程序的运行。在要安装的Windows组件前划勾，然后点“OK”，wine会自行帮助 下载 安装这些Windows部件。主要安装的Windows部件主要有：riched20，riched30，ie8，vcrun6，flash11，gdiplus，msls31，msxml6，vcrun2005，vcrun2008，winhttp组件，然后点击“OK”，安装好了相应的Windows部件。安装过程中会经常弹出需要用户选择“同意软件安装协议”等窗口，按照提示进行安装即可。至此，安装QQ的准备工作已经结束。

第三步：在腾讯官网上下载QQ最新版本，本文撰写时为QQ2012正式版。下载时选择保存，保存在某一目录下。下载完成后，点击右键QQ2012.exe，选择，“Open with wine program loader”，按照提示安装QQ即可，与在windows下安装QQ完全一样。

安装过程中，选择，发送到桌面快捷方式。这样在安装结束后，Ubuntu的桌面上就有QQ的图标，双击桌面图标，输入QQ帐号和密码，即可登录。
