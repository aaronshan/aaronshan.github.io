ubuntu 64位安装 RTX2012

本文详细介绍了在Linux系统中通过Wine软件安装RTX以实现内部通讯的方法，包括添加源、安装Wine、设置环境、安装依赖软件及最终安装RTX的过程。同时解决RTX在使用过程中遇到的问题。

Aaron2013-08-131 分钟阅读开发配置 · CSDN

公司用RTX来作为内部通讯之用，所以不得不使用WIne来安装RTX使用。说实话，我不是很喜欢WIne，因为对于有些软件支持的不是很好（虽然已经能很好支持很多软件了）。另外，用wine使用 windows 软件算怎么回事，不过没办法，谁让linux下没有同样的软件呢。

安装最新版的Wine。使用如下语句：

sudo apt-add-repository ppa:ubuntu-wine/ppa
sudo apt-get update

先把源添加并更新了再说。然后安装wine吧。

sudo apt-get install wine

接下来需要把wine的环境设置为32位的。（ 实践证明，不这样做的话，安装的RTX是没法用的）

export WINEARCH="win32"
sudo rm -rf ~/.wine
winecfg

安装依赖软件

winetricks msxml3 msxml6 riched20 riched30 ie6 vcrun6 vcrun2005sp1

msxml3可以在http://download.cnet.com/Microsoft-XML-Parser-MSXML-3-0-Service-Pack-7-SP7/3000-7241\_4-10731613.html下载。如果64位系统，安装msxml6时，要下载64位的 http://www.microsoft.com/en-us/download/details.aspx?id=3988。

64位的ubuntu需要把ie6改成ie8,有些软件如果下载不了，可以根据提示使用浏览器下载后，放到～/.cache/winetricks相应目录下，例如vcrun6就放在～/.cache/winetricks/vcrun6/下

下载RTX2012，下载地址为：http://dldir1.qq.com/foxmail/rtx/rtxclient2012formal.exe

直接打开rtx2012的 安装软件 安装，这过程会遇到一个组件未注册，忽略即可。安装成功后，就可以使用rtx了。rtx这时还有个问题，就是rtx会一直停留在离开状态，选择文件-个人设置-回复设置-自动状态切换把他勾掉就行。
