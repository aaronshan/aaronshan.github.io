ubuntu12.04 下安装RabbitVCS

本文介绍如何在Linux环境下安装并使用RabbitVCS，一款类似TortoiseSVN的图形化SVN管理工具。通过简单的步骤即可实现在Nautilus文件管理器中对SVN仓库的操作。

Aaron2013-08-091 分钟阅读开发配置 · Ubuntu · CSDN

windows 下常用的SVN管理工具是TortoiseSVN，而它不支持linux。如果你想在linux下也使用同样的图形化界面来管理SVN，那么RabbitVCS是一个不错的选择。它支持和TortoiseSVN同样的操作。

安装方法如下：

官方的wiki上指出了安装方法： http ://wiki.rabbitvcs.org/wiki/install/ubuntu

这里就再罗嗦一遍。首先添加PPA，

sudo add-apt-repository ppa:rabbitvcs/ppa

紧接着，执行语句sudo gedit /etc/apt/sources.list，在文件末尾添加如下语句：

deb http://ppa.launchpad.net/rabbitvcs/ppa/ubuntu **DISTRIBUTION** main

将其中的DISTRIBUTION替换为某一个特定版本的名称。比如：precise，其他的可参考：http://ppa.launchpad.net/rabbitvcs/ppa/ubuntu/pool/main/r/rabbitvcs/

随后执行语句更新软件源

sudo apt-get update

现在就可以安装了。语句如下：

sudo apt-get install rabbitvcs-nautilus3 rabbitvcs-thunar rabbitvcs-gedit rabbitvcs-cli

然后注销重新登录。ok,大功告成。
