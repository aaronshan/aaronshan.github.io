项目简介 📖

ragflow4j(https://github.com/aaronshan/ragflow4j) 是一个开源的 RAG（检索增强生成）引擎。与 Dify、Ragflow 等不同，它是用 Java 开发的。市面上类似的产品大多使用 Python 开发。我希望通过这个项目能帮助以 Java 为主要开发语言的开发者更好地理解 RAG 的整体机制。

1.2 关键实现细节

DocumentLoader 接口

public interface DocumentLoader {
    String load(Path path) throws IOException;
    CompletableFuture<String> loadAsync(Path path);
    boolean supports(Path path);
}

  • 定义了文档加载的核心接口

  • 支持同步和异步加载

  • 提供文件类型支持检查

AbstractDocumentLoader 抽象类

public abstract class AbstractDocumentLoader implements DocumentLoader {
    protected static final ExecutorService executor =
        Executors.newFixedThreadPool(Runtime.getRuntime().availableProcessors());

    @Override
    public CompletableFuture<String> loadAsync(Path path) {
        return CompletableFuture.supplyAsync(() -> {
            try {
                return load(path);
            } catch (IOException e) {
                throw new RuntimeException("Failed to load document: " + path, e);
            }
        }, executor);
    }
}

  • 实现了异步加载的通用逻辑

  • 使用线程池优化并发性能

  • 提供文件验证等通用功能

DocumentLoaderFactory 工厂类

public class DocumentLoaderFactory {
    private static final List<DocumentLoader> loaders = new ArrayList<>();

    static {
        registerLoader(new TextDocumentLoader());
        registerLoader(new PdfDocumentLoader());
        registerLoader(new WordDocumentLoader());
        registerLoader(new MarkdownDocumentLoader());
    }

    public static Optional<DocumentLoader> getLoader(Path path) {
        return loaders.stream()
            .filter(loader -> loader.supports(path))
            .findFirst();
    }
}

  • 采用工厂模式管理不同类型的文档加载器

  • 支持动态注册新的加载器

  • 提供自动文档类型识别和加载器选择
