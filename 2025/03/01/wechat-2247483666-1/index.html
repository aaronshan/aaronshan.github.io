项目简介 📖

ragflow4j （https://github.com/aaronshan/ragflow4j）是一个开源的 RAG（检索增强生成）引擎。与 Dify、Ragflow 等不同，它是用 Java 开发的。市面上类似的产品大多使用 Python 开发。我希望通过这个项目能帮助以 Java 为主要开发语言的开发者更好地理解 RAG 的整体机制。

今日工作内容 ✨

今天是项目开发计划的制定日。我们完成了以下重要工作：

  1. 1. 确定了技术栈 🛠

  • 核心开发语言：Java 8

  • 构建工具：Maven

  • 向量数据库：Milvus

  • 主要框架：Spring Boot 2.x, Spring Data JPA, DJL等

  1. 2. 制定了详细的开发计划 📅

  • 将项目分为8周开发周期

  • 每周专注于特定的核心功能模块

  • 制定了详细的每日任务分解

  1. 3. 规划了五大核心模块 🎯

  • 知识管理模块（文档处理、向量存储）

  • 代理管理模块（LLM集成、内容检索）

  • 技能管理模块（技能注册、版本管理）

  • 流程管理模块（工作流引擎）

  • 图形RAG模块（知识图谱）

  1. 4. 设定了关键里程碑 🏆

  • 第一个月：完成基础功能和核心服务

  • 第二个月：完成高级功能和Web界面

  1. 5. 制定了质量保证措施 ✅

  • 完整的单元测试覆盖

  • 规范的代码审查流程

  • 持续的性能优化要求

明日开发重点 🎯

  1. 1. 项目基础环境搭建

  • Maven多模块项目结构创建

  • Spring Boot基础框架配置

  • Milvus开发环境搭建

  1. 2. 依赖管理配置

  • parent pom文件创建

  • 核心依赖版本确定

  • Maven插件配置

  1. 3. CI/CD环境准备

  • GitHub Actions配置

  • 自动化构建流程设置

  • 测试框架集成

技术要点 💡

  1. 1. Java 8特性的充分利用

  • Lambda表达式和Stream API

  • 并发编程优化

  • 函数式接口设计

  1. 2. Spring生态系统集成

  • Spring Boot自动配置

  • Spring MVC Web服务

  1. 3. Milvus向量数据库

  • 连接池优化

  • 批量操作设计

  1. 2. 开发挑战

经验总结 📝
