项目简介 📖

ragflow4j(https://github.com/aaronshan/ragflow4j) 是一个开源的 RAG（检索增强生成）引擎。与 Dify、Ragflow 等不同，它是用 Java 开发的。市面上类似的产品大多使用 Python 开发。我希望通过这个项目能帮助以 Java 为主要开发语言的开发者更好地理解 RAG 的整体机制。

Content Scoring系统开发

开发目标

实现Content Scoring系统的核心功能，包括：

  • 评分接口设计

  • 评分计算引擎实现

  • 评分缓存机制设计

系统设计

评分接口设计

基于已有的ScoringService接口，我们实现了以下核心功能：

public interface ScoringService {
    CompletableFuture<List<ScoringResult>> score(String query, List<String> documents);
    CompletableFuture<List<List<ScoringResult>>> batchScore(List<String> queries, List<String> documents);
    void clearCache();
}

接口设计考虑了以下几个关键点：

  1. 1. 异步处理：使用CompletableFuture支持异步评分

  2. 2. 批量处理：提供批量评分接口提高性能

  3. 3. 缓存管理：支持缓存清理操作

评分计算引擎

实现了抽象基类AbstractScoringService，提供了以下功能：

public abstract class AbstractScoringService implements ScoringService {
    protected final Map<String, CompletableFuture<List<ScoringResult>>> cache;
    protected final ExecutorService executor;

    protected AbstractScoringService() {
        this.cache = new ConcurrentHashMap<>();
        this.executor = Executors.newFixedThreadPool(
            Runtime.getRuntime().availableProcessors()
        );
    }

    protected abstract String generateCacheKey(String query, List<String> documents);
    protected abstract List<ScoringResult> computeScores(String query, List<String> documents);
}
