项目简介 📖

ragflow4j(https://github.com/aaronshan/ragflow4j) 是一个开源的 RAG（检索增强生成）引擎。与 Dify、Ragflow 等不同，它是用 Java 开发的。市面上类似的产品大多使用 Python 开发。我希望通过这个项目能帮助以 Java 为主要开发语言的开发者更好地理解 RAG 的整体机制。

首先是EmbeddingModel接口的定义，这是整个向量化服务的核心接口：

public interface EmbeddingModel {
    /**
     * 将文本转换为向量表示
     *
     * @param text 需要向量化的文本
     * @return 向量化结果，包含向量数据和元信息
     */
    Response<Embedding> embed(String text);

    /**
     * 批量处理文本向量化
     *
     * @param texts 需要向量化的文本列表
     * @return 批量向量化结果
     */
    Response<List<Embedding>> embedBatch(List<String> texts);

    /**
     * 获取模型配置信息
     *
     * @return 当前模型配置
     */
    ModelConfig getConfig();
}

接下来是ONNX模型实现的核心部分：

public class OnnxEmbeddingModel extends AbstractInProcessEmbeddingModel {
    private final OnnxBertBiEncoder onnxBertBiEncoder;

    /**
     * 构造函数，初始化ONNX模型
     *
     * @param pathToModel 模型文件路径
     * @param pathToTokenizer 分词器文件路径
     * @param poolingMode 池化模式
     */
    public OnnxEmbeddingModel(Path pathToModel, Path pathToTokenizer, PoolingMode poolingMode) {
        super(null);
        this.onnxBertBiEncoder = loadFromFileSystem(pathToModel, pathToTokenizer, poolingMode);
    }

    @Override
    protected OnnxBertBiEncoder model() {
        return onnxBertBiEncoder;
    }
}

最后是向量化服务的工厂类实现：

public class EmbeddingFactory {
    private static final Map<String, EmbeddingModel> modelCache = new ConcurrentHashMap<>();

    /**
     * 获取或创建向量化模型实例
     *
     * @param modelConfig 模型配置信息
     * @return 向量化模型实例
     */
    public static EmbeddingModel getModel(ModelConfig modelConfig) {
        return modelCache.computeIfAbsent(modelConfig.getId(), id -> createModel(modelConfig));
    }

    private static EmbeddingModel createModel(ModelConfig modelConfig) {
        switch (modelConfig.getType()) {
            case ONNX:
                return new OnnxEmbeddingModel(
                    modelConfig.getModelPath(),
                    modelConfig.getTokenizerPath(),
                    modelConfig.getPoolingMode()
                );
            // 支持更多模型类型...
            default:
                throw new UnsupportedOperationException("不支持的模型类型");
        }
    }
}
